---
최근 구현된 작업 내용을 비판적으로 리뷰하고, 릴리즈 가능한 상태인지 보고해줘.

리뷰 항목:
- 요청/마일스톤 대비 구현 완성도
- 코드 구조 일관성 (기존 패턴 이탈 여부)
- 버그·엣지케이스 누락
- 테스트 통과 여부
- 추천 버전 (major / minor / patch)

차단 이슈는 수정까지 진행해도 됨. 단, 다음은 절대 수행하지 마:
git commit / git tag / git push

리뷰보고서 작성 — docs/reports/M{N}-review.md (대상 마일스톤 번호 M{N}에 맞춤):
- 비판점: 발견한 이슈 목록 (심각도: 차단 / 권장 / 사소)
- 수정 내용: 리뷰 중 직접 고친 항목과 그 결과
- 검증: 수정 후 테스트 통과 여부
- 릴리즈 판정: "가능 / 불가(사유)" + 추천 버전 (major/minor/patch)
- 다음 단계: 권장 후속 행동
  · 릴리즈 가능 → /tide-release vX.Y.Z (구체 버전 제시)
  · 불가 → 보완할 태스크 또는 /tide-milestone 로 후속 마일스톤 제안

리뷰·수정·리뷰보고서까지만 하고 최종 판정을 명확히 보고해줘.
