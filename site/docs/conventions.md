# 규약

tide는 **마일스톤 → 구현 → 리뷰 → 릴리즈** 사이클을 프로젝트 독립적인 슬래시
커맨드로 구현한 워크플로우입니다. 이 페이지는 각 단계가 따르는 형식·규칙을
정의합니다. 설계 원칙의 "왜"는 **[개념](concepts.md)** 을 참고하세요.

> 단일 원본으로 인클루드한 것입니다(사이트 전용 도입부만 위에 별도로 둡니다).
