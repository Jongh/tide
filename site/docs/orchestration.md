# 오케스트레이션 가이드

상위 폴더 단일 세션에서 여러 tide 자식 레포(MSA)를 가로질러 운용하는 **실전 사용법**을
정리한 how-to 가이드입니다 — 발견 → 의존·계약 선언 → 교차 사이클 자동화 → 통합 검증 →
순서대로 release 핸드오프. 규약의 배경과 정확한 정의는
**[규약](conventions.md)** 의 "멀티 레포 오케스트레이션" 절을 참고하세요.

> 아래 본문은 저장소 원본 [`docs/orchestration.md`](https://github.com/Jongh/tide/blob/main/docs/orchestration.md)를
> 단일 원본으로 인클루드한 것입니다(사이트 전용 도입부만 위에 별도로 둡니다).
