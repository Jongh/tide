# 릴리즈 게시 규약

`gh` CLI가 있는 저장소에서 `/tide:release`가 **GitHub 릴리즈를 생성**하거나 **릴리즈 브랜치 + PR**을
여는 게시 모드의 규약입니다. 규약 본체에서 분리된 **조각** 문서이며, 단계별 형식·규칙 전반은
**[규약](conventions.md)** 을 참고하세요.

> 아래 본문은 저장소 원본 [`docs/conventions-release.md`](https://github.com/Jongh/tide/blob/main/docs/conventions-release.md)를
> 단일 원본으로 인클루드한 것입니다(사이트 전용 도입부만 위에 별도로 둡니다).
