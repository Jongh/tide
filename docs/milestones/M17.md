# M17 — 오케스트레이션 2층 sub-step: 계약 버전 비교(`upstream behind` 경고) + `.tide/deps` BOM 내성

## 목표

이 마일스톤이 끝나면 **`/tide:fleet`이 `.tide/deps`의 의존 줄에 선언된 최소 버전 제약을 의존 대상
레포의 현재 버전과 비교해, 상류가 요구 버전에 못 미치면 "blocked: upstream behind" 경고를 advisory로
띄운다.** 예: `svc-orders/.tide/deps`에 `svc-auth >= v0.3.0`인데 svc-auth가 v0.2.0이면, fleet이
"svc-orders는 svc-auth ≥ v0.3.0을 요구하나 현재 0.2.0 — 먼저 svc-auth를 올려야 함"을 표기한다.
버전 제약 없는 의존 줄은 M16 그대로(이름 의존만)다. 더불어 `.tide/deps` 파서가 **선두 UTF-8 BOM을
무시**해, Windows 편집기/`Set-Content -Encoding utf8`로 만든 BOM 붙은 deps 파일도 첫 줄(주석·의존)이
올바로 파싱된다. 두 변경 모두 옵트인·하위 호환이고 fleet은 여전히 읽기 전용·advisory만(경고도 제안일
뿐 자동 차단·실행 없음). 커맨드 9종·1.0 계약·부수효과 분리 불변.

## 배경

M16(v1.3.0)이 오케스트레이션 2층(이름 기반 의존 → 위상정렬 권장 순서)을 세웠고, M16-review가 **계약/
버전 비교를 2층 sub-step 후속**으로 명시했다("상류가 뒤처지면 blocked: upstream behind 경고"). MSA에서
의존은 "auth가 있다"가 아니라 "auth API가 v0.3.0 이상이어야 한다"인 경우가 많으므로, 버전 제약 비교는
2층의 자연스러운 다음 단계다.

또한 v1.3.0 fleet의 **라이브 실증 중 발견**: 샌드박스 `.tide/deps`를 `Set-Content -Encoding utf8`로
생성하면 선두에 UTF-8 BOM이 붙는데, PowerShell `Get-Content`(expect/run.ps1)는 BOM을 자동 처리하나
`run.sh`의 `read_deps`는 BOM+`#` 첫 줄을 주석으로 못 거를 수 있다(테스트 픽스처는 `printf`라 BOM 없음
→ 미검출). 실사용에서 deps 파일에 BOM이 붙는 경로가 있으므로 파서의 BOM 내성을 같은 사이클에 넣는다.

메타 규칙("규약↔실행/인프라 동기화"): 새 규약(계약 버전·BOM 무시)을 더하면서 검증 실증을 같은 사이클에.

## 정규 spec (이 마일스톤의 단일 기준 — T01·T02·T03이 모두 이를 인용)

### `.tide/deps` 계약 버전 (옵트인 확장)

- **형식**: 의존 줄에 선택적 버전 제약을 붙인다 — `<형제 레포명>[ >= <버전>]`. 예: `svc-auth >= v0.3.0`.
  연산자/버전이 없으면 **이름 의존만**(M16 동작 그대로). 토큰 사이 공백은 트림한다.
- **연산자**: 이번 sub-step은 **`>=`(최소 버전)만** 지원한다("이 버전 이상 필요" — 의존 계약의 지배적
  의미). `>`·`=`·`<=`·`<` 등은 후속(범위 밖). `>=` 외 연산자가 오면 **무시하고 경고**(안전 측 — 미달로
  단정하지 않음).
- **버전 파싱·비교**: 버전은 `vX.Y.Z`(선행 `v` 선택)로 보고 **major.minor.patch를 숫자로** 비교한다.
  의존 대상 레포의 **버전 파일 현재 버전**(fleet 상태 조회 4번 항목)을 읽어, `현재 >= 요구`면 만족,
  아니면 **위반(upstream behind)**. 버전 파싱 불가(비표준)면 **비교 생략 + 경고**(차단으로 단정 안 함).
- **의미·출력**: 위상정렬 순서·의존 그래프는 M16 그대로(버전 제약은 순서를 바꾸지 않는다). 위반이면
  **권장 순서/advisory에 경고를 표기**한다 — 예: `svc-orders → ⚠ svc-auth 0.2.0 < 요구 >= 0.3.0
  (upstream behind — svc-auth를 먼저 올릴 것)`. 경고는 **advisory만** — fleet은 차단·실행하지 않는다.
- **옵트인·하위 호환**: 버전 제약 없는 줄·deps 미선언은 현행 동작 불변.

### `.tide/deps` BOM 내성

- deps 파서(스킬·sh·ps1 참조 구현)는 파일을 읽을 때 **선두 UTF-8 BOM(`EF BB BF`)을 제거**한 뒤
  줄 단위 파싱한다(주석 `#`·빈 줄 무시·트림은 M16 그대로). 이로써 BOM 붙은 첫 줄도 올바로 처리된다.
- 규약(conventions)의 `.tide/deps` 포맷 서술에 "선두 BOM은 무시한다"를 한 줄 추가한다.
