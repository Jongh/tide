# M3 — 스킬 구조 전환(네이밍 정리 포함) + 문서-실동작 일치 + 패키지 위생

## 목표

커맨드 6종을 공식 권장 형식인 `skills/{이름}/SKILL.md` 구조로 전환하면서 `tide-`
접두사 중복을 함께 제거해 `/tide:milestone`, `/tide:status`처럼 자연스러운 호출을
만들고, 템플릿을 해당 스킬에 동봉한다. README·규약·커맨드 본문의 모든 호출 표기를
실제 동작과 일치시키고, 설치 패키지의 불필요 파일 포함 문제를 해소하거나 결정을
기록한다.

## 배경

v0.3.0 릴리즈 후 권장 작업 검증 중, 플러그인 커맨드가 네임스페이스 형태로만 호출됨을
발견했다 — `/tide-status`(README 표기)는 동작하지 않고 `/tide:tide-status`만 동작한다.
플러그인명(tide)과 파일명 접두사(tide-)가 겹쳐 호출이 이중으로 어색하고, 문서와
실동작이 어긋난 상태다.

스킬 구조 전환은 당초 백로그였으나 사용자 요청으로 타당성을 조사한 결과 M3 포함으로
확정했다: 공식 문서상 SKILL.md는 커맨드와 frontmatter(`argument-hint` 포함)·`$ARGUMENTS`
치환·호출 UX가 완전 동일(기능 손실 없음)하고, 접두사 제거 rename과 구조 전환이 같은
파일 이동 한 번으로 끝나므로 미루면 같은 파일을 두 번 옮기게 된다. 추가 이득으로
`${CLAUDE_SKILL_DIR}` 치환과 스킬별 부속 파일 동봉이 열린다. 패키지 위생은 M2
리뷰보고서 권장 3번의 후속이다.

## 태스크 목록

- M3-T01: 커맨드 6종을 `skills/{이름}/SKILL.md` 구조로 전환 (`tide-` 접두사 제거 겸)
- M3-T02: 템플릿 3종을 해당 스킬 디렉터리로 이동, `${CLAUDE_SKILL_DIR}` 참조로 전환 (deps: M3-T01)
- M3-T03: 스킬 본문의 상호 호출 표기를 `/tide:{이름}`으로 갱신 (deps: M3-T01)
- M3-T04: README·conventions 표기 전면 통일 + 마이그레이션 노트 보강 (deps: M3-T01)
- M3-T05: 패키지 위생 — 파일 제외 수단 조사 후 적용, 불가하면 결정 기록
- M3-T06: 도그푸딩 재설치 + 새 세션 검증 (deps: M3-T01, M3-T02, M3-T03, M3-T04)

## 태스크 상세

### M3-T01: 커맨드 6종을 skills 구조로 전환

`commands/tide-{이름}.md` 6종을 `git mv`로 `skills/{이름}/SKILL.md`에 옮긴다
(kickoff / milestone / impl / review / release / status — 이력 보존). 호출명은
`/tide:kickoff` … `/tide:status`가 된다. frontmatter는 기존 `description`·
`argument-hint`를 그대로 유지한다(SKILL.md 동일 지원 확인됨). `commands/` 디렉터리는
비우고 제거한다(공식상 병존 가능하나 단일 원본 원칙 유지). 내장 스킬(/review 등)과의
이름 충돌은 플러그인 네임스페이스가 방지하므로 무시한다.

### M3-T02: 템플릿의 스킬 동봉 전환 (deps: M3-T01)

템플릿 3종이 각각 정확히 하나의 스킬에 대응하므로 해당 스킬 디렉터리로 옮긴다:
- `templates/milestone.md` → `skills/milestone/template.md`
- `templates/impl-report.md` → `skills/impl/template.md`
- `templates/review-report.md` → `skills/review/template.md`

각 SKILL.md의 템플릿 참조를 `${CLAUDE_PLUGIN_ROOT}/templates/…`에서
`${CLAUDE_SKILL_DIR}/template.md`로 교체한다. **폴백**: `${CLAUDE_SKILL_DIR}` 치환이
기대대로 동작하지 않으면 중앙 `templates/` + `${CLAUDE_PLUGIN_ROOT}` 방식을 유지하고
사유를 기록한다 (치환 동작은 verbatim 에코 드라이런으로 확인 — M2 검증 절차 재사용).
빈 `templates/` 디렉터리는 제거. 기존 폴백(템플릿 못 읽으면 섹션 목록) 문구는 유지.

### M3-T03: 스킬 본문의 상호 호출 표기 갱신 (deps: M3-T01)

각 스킬이 다음 단계로 안내하는 호출 표기를 전부 새 형태로 교체한다 —
kickoff·status의 "다음: /tide-milestone", impl 전제조건의 "/tide-milestone 먼저",
review의 "/tide-release vX.Y.Z" / "/tide-impl 먼저", 가드 스크립트 차단 메시지의
"/tide-release"(sh·ps1 두 곳) 포함. 누락 검출은 저장소 전체에서 `/tide-` 패턴
grep으로 확인한다 (이력 문서 docs/milestones/·docs/reports/와 CHANGELOG는 제외).

### M3-T04: README·conventions 표기 통일 + 마이그레이션 노트 보강 (deps: M3-T01)

- README: 사이클 다이어그램, 커맨드 표, 설치 절, 명명 규약 절(접두사 묶음 설명을
  네임스페이스 설명으로 교체 — "`/tide:` 까지 입력하면 자동완성"), 저장소 구조 절
  (`commands/`·`templates/` → `skills/`)을 새 구조·호출명으로 통일. 수동 복사 설치
  절도 skills 경로 기준으로 갱신
- 마이그레이션 노트에 v0.3.0 → v0.4.0 호출명 변경(구 `/tide:tide-*` → `/tide:*`) 추가
- conventions: 사이클 다이어그램·전제조건 표·금지 행위 표의 호출 표기, 템플릿 절의
  위치 서술("templates/ 단일 원본" → "각 스킬 디렉터리의 template.md") 갱신

### M3-T05: 패키지 위생 — 파일 제외 수단 조사 및 적용

설치 캐시에 `docs/`(이 저장소의 사이클 기록 전체)와 `.claude/`(도그푸딩 설정)가
포함되는 문제. 우선 plugin.json/marketplace.json에 파일 제외(ignore/files 필터)
수단이 공식 지원되는지 문서로 조사한다.
- 지원되면: 적용해 `skills/`·`hooks/`·매니페스트·README만 패키지에 남김
- 미지원이면: 구조적 우회(docs 분리 등)는 비용 대비 이득이 작으므로 **수용**으로
  결정하고 그 근거를 리뷰보고서에 기록 (저장소 구조를 흔드는 우회는 이번 범위가 아님)

### M3-T06: 도그푸딩 재설치 + 새 세션 검증 (deps: M3-T01~T04)

구조 전환은 설치된 플러그인 캐시에 자동 반영되지 않으므로 로컬 마켓플레이스로
재설치한 뒤 새 세션(headless)에서 검증한다:
1. `/tide:status`가 동작하고 구 `/tide:tide-status`는 Unknown command가 된다
2. 가드 hook 차단/통과가 구조 전환과 무관하게 동일 동작
3. `/tide:milestone`의 템플릿 참조가 유효한 경로로 치환된다 (verbatim 에코 드라이런)
검증 후 마켓플레이스 등록을 원래 상태(GitHub)로 되돌린다 — GitHub 재등록은 릴리즈
후에만 새 커밋을 반영하므로 릴리즈 전 검증은 로컬 경로로 수행한다.

## 파일 변경 요약

| 구분 | 파일 |
|---|---|
| 이동 | `commands/tide-*.md` 6종 → `skills/{kickoff,milestone,impl,review,release,status}/SKILL.md` |
| 이동 | `templates/*.md` 3종 → `skills/{milestone,impl,review}/template.md` |
| 수정 | 전환된 SKILL.md 6종 본문 (상호 호출 표기, 템플릿 참조) |
| 수정 | `hooks/tide-guard.sh`·`tide-guard.ps1` (차단 메시지의 호출 표기) |
| 수정 | `README.md`, `docs/conventions.md` |
| 수정 | (T05 결과에 따라) `.claude-plugin/plugin.json` 또는 `marketplace.json` |
| 삭제 | `commands/`, `templates/` 디렉터리 (이동 후 빈 디렉터리) |

## 완료 기준

1. 플러그인 재설치 후 새 세션에서 `/tide:status` 호출 시 상태 보고가 동작하고,
   `/tide:tide-status`는 Unknown command가 된다
2. `/tide:milestone` 드라이런에서 템플릿 경로가 유효한 절대경로로 치환되고 해당
   파일을 읽을 수 있다 (`${CLAUDE_SKILL_DIR}` 또는 폴백 방식)
3. 이력 문서(docs/milestones/·docs/reports/·CHANGELOG)를 제외한 저장소 전체에서
   `/tide-` 호출 표기가 grep으로 검출되지 않는다
4. phase=impl 상태에서 git commit 시도 시 가드가 새 표기(`/tide:release`)의 안내
   메시지로 차단한다
5. T05 조사 결과가 적용(캐시에 docs/·.claude/ 미포함) 또는 수용 결정 기록 중
   하나로 마무리된다
6. README 마이그레이션 노트가 구 호출명 사용자를 새 호출명으로 안내한다
