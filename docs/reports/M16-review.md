# M16 리뷰보고서 (review)

## 비판점

리뷰 결과 **차단 0건**. M16 세 태스크는 완료 기준을 충족하고, `/tide:fleet`이 `.tide/deps` 기반
의존성 인식 권장 순서를 내놓는 오케스트레이션 2층이 갖춰졌다. 3-way 병렬 산출물(규약·스킬·테스트)이
정규 spec을 공통 인용해 서로 일치함을 확인했다.

### 차단 (0건)

없음. 옵트인 가산(미선언 시 현행 동작 불변)이고, fleet은 여전히 읽기 전용·advisory만(위상정렬 순서를
제안만, cross-repo git 비자동화), `.tide/phase`·tide-guard·커맨드 9종·1.0 계약을 건드리지 않는다.

### 권장 (1건 — 후속 우선순위)

1. **계약/버전 비교(2층 sub-step)** (M16-impl#1) — 이번은 **이름 기반 의존만**이다. `svc-auth >= v0.3.0`
   같은 계약/버전 인식(상류 레포가 뒤처지면 "blocked: upstream behind" 경고)은 의존성 인식의 자연스러운
   다음 단계다. M16 범위에서 의도적으로 제외했으니 차단이 아니며, 다음 사이클(2층 sub-step) 또는 3층
   진입 전 우선순위로 둘 후보다.

### 사소 (3건)

2. **기존 프로젝트 gitignore 마이그레이션** — gitignore 범위를 `.tide/`→`.tide/phase`로 좁혀 신규
   프로젝트(kickoff)는 `.tide/deps`를 커밋할 수 있다. 단 **이미 `.tide/`로 무시 중인 기존 프로젝트**는
   deps를 채택하려면 자기 `.gitignore`를 직접 좁혀야 한다(자동 마이그레이션 아님). 옵트인 기능이라
   채택 시 1회 조정으로 충분하지만, README 마이그레이션 노트에 한 줄 두면 친절하다(저위험, 후속).
3. **참조 구현 이중성(이월)** — 위상정렬을 스킬 산문 + 하니스가 각자 표현. conventions 단일 원본으로
   완화했으나 규약 변경 시 동기화 부담 잔존. 저위험·수용.
4. **fleet 세션 레벨 순서 출력 재확인** — 위상정렬·순환 폴백의 결정적 핵심은 하니스로 덮었으나, 실제
   `/tide:fleet`이 `.tide/deps` 선언된 샌드박스에서 권장 순서를 기대대로 출력하는지는 수동 확인 영역
   (README). 멀티 레포 실투입 전 1회 권장(M13~M15에서도 릴리즈 후 in-session에 닫은 성격).

## 검증

- **라이브 하니스**: `sh tests/fleet/run.sh` → **PASS=15 / FAIL=0**, `tests\fleet\run.ps1` → **PASS=15 /
  FAIL=0**(non-ASCII 바이트 0). 회귀: `sh tests/multi-repo/run.sh` → exit 0.
- **신규 시나리오 검증**: 위상정렬에서 auth가 orders·gateway보다 앞(인덱스 비교), 미선언 solo 순서 존재,
  미존재명(`nowhere`) 무시(4노드·크래시 없음), 순환 a↔b `CYCLE` 폴백 감지. 기존 9건(발견·5분류·1:1
  요약·숨김·강등) 유지.
- **gitignore 변경 안전성**: `git check-ignore`로 `.tide/phase`는 무시(`.gitignore:2`), `.tide/deps`는
  **미무시(커밋 가능)** 확인. `.tide/phase`는 종전대로 추적 안 됨(워킹트리에 `.tide/*` 미노출) —
  `.tide/phase` 의미·tide-guard 계약 불변(1.0 정합).
- **병렬 산출물 정합**: conventions("멀티 레포 오케스트레이션" 절, 단일 원본) ↔ fleet 스킬 ↔ tests/fleet이
  동일 spec(`.tide/deps` 포맷·위상정렬 피의존 우선·순환 폴백·미선언 독립·미존재 무시)을 서술. 통과하는
  하니스가 규약의 결정적 동작을 고정.
- **불변 보존**: fleet 읽기 전용·부수효과 분리(advisory만·cross-repo git 비자동화)·정규 5버킷 요약(M15)
  유지. 1.0 안정성 절·커맨드 9종 framing 무변경.
- **제외 용어**: M16 신규/변경 텍스트(conventions 신규 절·fleet 스킬·kickoff·tests/fleet·M16 문서)에 외부
  저장소명 literal 0. 기존 `conventions.md:3`은 snippet 마커 밖(미변경). 빌드 출력 검증은 release/CI.
