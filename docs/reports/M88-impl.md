# M88 완료보고서 (impl)

## 개요

M88의 일곱 태스크를 구현했다. 규약 "새 하니스가 갖출 공통 통제" 절의 「집행」이 판정 이름 선언 `hc-asks:`(열일곱 이름) · 케이스 대응 `hc-ask-cases:` · 시작 케이스 `hc-ask-from:`과 이름별 정의 항목이 됐다(T02). `tests/discover` Part K는 `K7`~`K25`를 더했다 — 선언 위생은 등록표 행이 내고, 대응 판정은 안전 바닥 축이 쓰던 함수를 축의 키와 파트 표지를 인자로 받게 넓힌 `ak_*` · `Ak*`가 낸다(T03).
C3 · C4의 명단 크기 기대값은 손 상수 `6` · `11`이 아니라 규약 문장의 수에서 읽는다(T04). `mark-since-steps:` 재서술처 창 안 이름의 차례 판정(`O118` · 통제 `O119`)과 규약 조각 문서 발견 통제(`O120`)를 더했다(T05 · T06). 규약 · 하니스 README · 에픽을 맞췄다(T07).
태스크가 모두 같은 두 러너 파일과 규약을 고친다(파일 충돌 안전장치의 겹침 — T02 · T07은 규약, 나머지는 두 러너). 그래서 서브에이전트를 쓰지 않고 메인이 위상 순서대로 차례로 구현했다.

재작업 라운드(rework): 0
